ISMOIL — PERSONAL PORTFOLIO

1. Extract the ZIP file.
2. Open index.html in a browser. No build tools or installation are required.
3. The profile photo is in assets/ismoil-portrait.png.

CUSTOMIZE BEFORE PUBLISHING
- In index.html, replace hello@example.com with your real public contact email (there are two occurrences).
- Update the About and interests text to reflect your real experience.
- Add real project cards when you have projects to showcase.
- You can replace assets/ismoil-portrait.png with another portrait, keeping the same filename.

FEATURES
- Uzbek / English language toggle
- Light / dark theme toggle (preference is saved in the browser)
- Responsive layout and mobile navigation
- HTML, CSS and vanilla JavaScript only
